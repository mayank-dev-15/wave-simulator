## About

**wave-simulator** is a physics-based wave interference simulator.

### Key Features

- 2D wave propagation on HTML5 Canvas
- Multiple wave sources (click to add/remove)
- Real-time interference pattern visualization
- Circular, plane, and standing wave types
- Adjustable frequency, amplitude, wavelength
- Constructive & destructive interference
- Color-mapped amplitude visualization
- Double-slit, Doppler, Resonance presets
- Grid overlay toggle
- Pause/reset controls

---

## Tech Stack

- HTML5 Canvas 2D
- CSS3
- Vanilla JavaScript
- requestAnimationFrame

---

## Controls & Usage

| Control | Action |
|---------|--------|
| `Click empty space` | Add wave source |
| `Click+drag source` | Move source |
| `Shift+click source` | Remove source |
| `Space` | Pause/resume |
| `R` | Reset |
| `S` | Slow-motion |
| `G` | Toggle grid |
| `1-6` | Load presets |
