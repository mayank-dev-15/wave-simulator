# wave-simulator

[![Live Demo](https://img.shields.io/badge/🚀_Live_Demo-Visit-blue?style=for-the-badge)](https://mayank-dev-15.github.io/wave-simulator)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
![Language](https://img.shields.io/badge/Language-HTML/CSS/JS-green)

Physics-based wave interference simulator with multiple wave sources, real-time interference patterns, and scientific presets.

`physics` `waves` `simulation` `canvas` `interactive`

---

## ✨ Features

- 2D wave propagation on HTML5 Canvas
- Multiple wave sources (click to add/remove)
- Real-time interference pattern visualization
- Circular, plane, and standing wave types
- Adjustable frequency, amplitude, wavelength per source
- Constructive & destructive interference
- Color-mapped amplitude (blue=negative, red=positive)
- Presets: Single Slit, Double Slit, Doppler, Resonance
- Grid overlay toggle
- Pause/reset/slow-motion controls

## 📦 Installation

```bash
git clone https://github.com/mayank-dev-15/wave-simulator.git
cd wave-simulator
```

No build step needed. Just open `index.html` in your browser:
```bash
open index.html
```

---

## 💡 Usage

- Click anywhere to add a wave source
- Shift+click a source to remove it
- Use sliders to adjust frequency, amplitude, wavelength
- Press Space to pause/resume
- Press S for slow-motion mode
- Press 1-6 to load physics presets
